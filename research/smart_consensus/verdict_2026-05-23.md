## 信号构造

```python
# 1. Smart cube filter
smart = profile[
    (annualized_gain_rate > 25%) AND
    (annualized_gain_rate <= 200%) AND   # exclude 模拟盘 outliers
    (followers_count >= 200) AND
    (n_user_events >= 30) AND
    (active_days >= 365)
]  # 96 cubes

# 2. Skill weight (log-clipped, sum-normalized)
skill_weight(cube) = log1p(clip(ann_gain, 25, 200)) / sum

# 3. Per-stock signal
signal(stock, week) = SUM_smart_cubes [ skill_weight × portfolio_weight ]

# 4. Implementation: avoid stocks where signal > 0; pick from out-of-pool (signal == 0)
```

## Caveats（必须诚实）

1. **退市股偏差**：foundation audit 报 ~1-3%/yr alpha inflation（panel 不含退市股）。折扣后真实 excess ~10-12%/yr
2. **Size bias 未控制**：median in-pool=2,196 stocks, out-pool=1,128 stocks。smart cubes 可能偏好大中盘，out-pool 偏小盘。2024 A 股小盘狂涨 (CSI1000 ~+30%) → test +40% 含小盘 beta
3. **2024-2026 单一 regime**：只有 17 个月 OOS。pre-2022 OHLCV 拉到后可以扩展到 11 年验证（PR #5 Tanglaoye 在跑）
4. **Liquidity 未筛**：out-pool 可能含低成交量股票，实盘 slippage 高于 56bp 假设

## 解释（为什么这个方向有理）

行为学：smart cubes 是雪球关注度高的 KOL，他们的持仓自带"曝光效应"。粉丝跟单 → 流动性涌入 → 股价被推高 → mean reversion 让这些股票后续跑输。

数据上的具体表现：
- 同样质量的两只股票，smart cubes 重仓的那只下周期望收益比另一只低 ~1.6%
- 这个差距在大盘各种 regime 下持续存在 (年年负 IC)
- 是 stockpicking alpha，不是 timing alpha
