# 可转债领先正股 Alpha 研究说明

## 结论摘要

这份报告建议优先验证一个新的 A 股 Alpha 方向：**可转债市场信号是否领先对应正股未来一周收益**。当前公开 checkout 没有足够数据直接完成严谨实验，因此本 PR 不提交回测结论，只提交一套可在作者本地数据环境执行的研究方案和清单。

本方向值得测试，但不能直接相信。它必须通过历史可转债全集、点时转股价、强赎事件过滤、正股复权收益、成本后收益和样本外检验之后，才能进入下一阶段。

## 为什么不是继续做旧方向

仓库现有研究已经反复暴露几个问题：常见选股因子样本外衰减明显，短线题材和涨停类信号容易把不可成交的隔夜跳空当成收益，社交/共识类信号容易受样本、流动性和成本影响。继续在这些路径上调参数，边际价值不高。

可转债方向的优势在于它不是单纯从正股历史价格里再挖一个变体，而是利用同一家公司在另一个可交易资产上的信息反应。它有清晰机制，也有明确的证伪方式。

## 经济机制

可转债同时包含债底、转股权、信用风险、赎回/下修条款和正股权益敞口。A 股正股是 T+1，而可转债是 T+0，且转债投资者会密切关注转股溢价率、强赎风险、下修预期和正股波动。

如果部分信息先体现在转债市场，可能出现以下现象：

- 转股溢价率提前压缩，随后正股上涨或风险重估；
- 转债成交和价格相对正股出现异常，反映更快的资金反应；
- 条款事件附近的价格变化会污染普通信号，需要单独过滤；
- 信号可能只在流动性较好的转债样本中存在。

本 PR 锁定第一个最简单假设：**20 个交易日转股溢价率压缩，是否预测正股未来一周收益**。

## 最小严格实验

详细执行清单见 `docs/superpowers/plans/2026-05-19-cb-leadlag-experiment.md`。核心设定如下：

- 样本：历史所有可转债，包括已退市、已赎回个券；
- 信号日：每周最后一个可交易日；
- 因子：`factor = -(premium_rt[t] - premium_rt[t-20])`；
- 溢价率：用点时转股价和正股未复权收盘价重算；
- 正股收益：用复权收盘价计算 `t+1` 到 `t+6`；
- 事件过滤：headline 指标只能过滤 `t` 时已经知道的强赎事件，不能用未来事件；
- 指标：周度横截面 rank IC、long-only top quintile 相对同宇宙等权收益、纸面 top-bottom spread；
- 随机对照：每周在同一个 CB-linked universe 内随机抽取同等规模组合，最终看 `signal excess - random excess`；
- 成本：默认 56 bp round-trip，并做 20 bp / 100 bp 敏感性；
- 样本外：2025-07-01 之后只允许在参数冻结后运行一次。

## 通过标准

严格通过需要同时满足：

- 样本内 mean rank IC >= 0.03；
- 样本内 IC t-stat >= 2.5；
- 样本内成本后 long-only excess return > 0；
- 样本内 random-control mean IC < 0.005；
- 样本内 signal IC - random IC > 2 倍标准误；
- 样本内 signal excess - random excess > 0；
- 样本外 IC 同号且 >= 0.015；
- 样本外 IC t-stat >= 1.5；
- 样本外成本后 long-only excess return > 0。

如果只用当前存续转债样本，即使结果很好，也只能标记为 `INSUFFICIENT_EVIDENCE` 或 smoke-test `continue`，不能标记为验证成功。

## 最容易犯错的地方

1. 使用当前转债列表回填历史，会产生幸存者偏差。
2. 使用最新转股价重算历史溢价率，会产生前视偏差。
3. 用复权价算转股价值，或用未复权价算正股收益，都会污染结果。
4. 用 `t+10` 之后发生的强赎事件过滤 `t` 的信号，是未来信息。
5. 只看 top-bottom spread 会高估可交易性，因为 A 股融券约束明显。
6. 看到第一次结果后改窗口、改持有期、改因子定义，会把研究变成参数搜索。

## 给作者的执行建议

请先不要跑大规模网格。建议按以下顺序执行：

1. 补齐本地数据并生成 `data_inventory.md`；
2. 先让脚本确认是否能进入 `strict` 模式；
3. 只跑锁定的 20D 溢价率压缩 / 5D forward return 版本；
4. 样本内通过后写 freeze manifest；
5. 再运行一次样本外；
6. 报告最后只给三种结论之一：`VALIDATED_FOR_NEXT_STAGE`、`REJECTED`、`INSUFFICIENT_EVIDENCE`。

如果严格实验失败，建议直接记录否决，不要在同一批数据上继续尝试 10D、30D、CB-return residual、波动率偏离等变体。那些可以作为下一轮预注册实验，但不能在本轮失败后临时切换。

如果 CB → 正股方向被否决，下一轮可以单独预注册反向的“正股 → 可转债 lead-lag”实验。这个假设也合理，因为部分正股流动性远高于转债，信息可能先进入正股再传导到转债。但它不能和本轮实验混跑，否则会形成事后择优。

## 为什么这份 PR 有价值

这份 PR 的目的不是声称发现 Alpha，而是把一个有机制的新方向转成可被证伪的实验。它要求作者在本地数据环境里回答一个清晰问题：

> 在避免幸存者偏差、转股价前视、强赎事件泄露和交易成本之后，可转债溢价率压缩是否仍然能预测正股未来收益？

如果答案是否定的，应尽快停止；如果答案是肯定的，下一阶段再研究组合约束、流动性容量、行业中性、事件分层和实盘信号生成。
