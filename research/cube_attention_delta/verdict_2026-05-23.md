## TL;DR

DeepSeek 2026-05-21 报告的 momentum_short test IC = +0.0268 **是 145 股稀疏样本的统计噪音**。补齐到 4,813 股有效样本后：

1. **方向翻转**：momentum_**long**（不是 short）才是正方向，但 IC 仅 +0.0037
2. **vs 同 universe random**：年化超额 +0.14%（基本为零）
3. **加成本后**：CAGR -20.05% vs Random -20.61% — 信号 ≈ 通用 beta
4. **OOS 失败**：train IC=+0.0061, test IC=+0.0018 (t=0.76, 不显著)

→ **REJECTED**：cube_count 的 4-week momentum 没有可交易 alpha。

## 为什么 DeepSeek 之前的 +0.0268 IC 是噪音

DeepSeek 报告时只有 145/5,429 = 2.7% 股票有 daily_k，**且这 145 只是字典序前 145 个（000001-000608 段）**——全是早编号的国企/大盘 stocks，universe 极度偏斜。

补齐后 4,813 股横截面取 IC，原信号几乎完全消失。Random control IC 也从 +0.0071（稀疏导致）降到 +0.0001（正常）。

## 与历史经验一致

CLAUDE.md 早就警告过这个失败模式：

> True Alpha = Signal - Random Control, NOT Signal - HS300.
> If Signal ≈ Random Control, the "alpha" is just beta to the universe.

bili_stock 历史所有 cube_count 衍生信号（static count / industry-neutral / delta / momentum / accel）全部在这条规则下倒下：

| 因子 | 来源 | 状态 |
|---|---|---|
| Static cube_count | baseline_v6.1 | raw alpha 5.3%, cost-adj < 0 |
| Cube count delta | Task 014 | IC = +0.0004, REJECTED |
| Cube count momentum | Task 014 | IC = +0.0037 vs noise, **vs same-universe random ≈ 0**, REJECTED |
| Cube count acceleration | Task 014 | IC = -0.0005, REJECTED |

## 结论

**Cube_count 作为单维信号已经穷尽。** 静态、变化率、动量、加速度全部测过，都没有 cost-adjusted alpha。

下一步建议（如果还想挖 cubes 数据）：

1. **不再做 cube_count 衍生因子** — 不会有不同结果
2. **转向调仓行为本身** — 哪个组合、加仓还是减仓、仓位变化幅度 → Brief A' 已经在做（dynamic flow）
3. **或者彻底关闭 cubes 线** — 9 个月研究有结果（baseline_v6.1 的 5.3% raw alpha 是真的，只是成本吃了），心安转向其他方向（poly_strategy issue #11）
