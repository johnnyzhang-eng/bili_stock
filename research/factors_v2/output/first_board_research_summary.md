# 一进二板战法研究总结 (2026-04-27)

## TL;DR

**一进二板战法对散户不可行**。65,503 笔事件 / 16 年数据下：
- 唯一显著正 alpha 的版本（H1b 尾盘抢板）含有 ex-post 信息，无法实盘执行
- 所有真正可执行版本（次日 open 进场）alpha 不显著或显著为负
- 真实存在的 +2% alpha 集中在 **T 日 close → T+1 open 的隔夜跳空**，散户拿不到

这是一个 **limits to arbitrage** 案例：市场低效真实存在，但被结构性信息+时序优势 priced in 给了游资，散户站在 trade 的另一边。

## 关键发现

### 1. 隔夜跳空是真实低效（不是 backtest bug）

H1b 的 +1.87% alpha 在以下维度全部稳健：
- **17 年稳定**：2010-2026 所有年份均正显著，零负年
- **Bootstrap 95% CI**：[+1.817%, +1.933%]，完全在 0 之上
- **Cost 敏感性**：alpha 不随 cost 变（signal/random 都扣同样 cost）
- **行业普适**：Top 12 行业里大部分都正显著

这意味着 **A 股涨停股票次日确实有平均 +2% 的隔夜跳空**——这是真实存在的统计现象。

### 2. 但散户拿不到这 +2%

把 entry 从 T 日 close 改成 T+1 open（增加 1 个交易日的 1 个开盘价点），alpha 几乎完全消失：
- H1b alpha +1.87% → H1 alpha -0.18%（消失 +2.05%）
- 这 +2.05% 就是 **T close → T+1 open 的隔夜跳空 alpha**，散户在 T+1 open 进场时已经付掉了

### 3. 铁板是最坑的板（反散户共识）

V1 铁板（盘中没开过板的真硬封板）alpha 反而**最负**（-0.63% t=-12.61），且**胜率仅 6.7%**：
- 物理机制：铁板 = 全天没增量卖盘 = 次日开盘高开溢价饱和 → 高开后无新增买力 → 整日卖压回落
- 散户共识"铁板强、续涨概率高" → 数据完全反过来
- **机械化执行 V1 = 100 笔里 93 笔亏**

### 4. "0-5% 追板"民间智慧无效（V3 alpha +0.04% 不显著）

54,288 笔过滤后 alpha 仅 +0.04%/笔，t=+1.69 不达显著线。"次日不破 0 轴 + 0-5% 高开"在 16 年数据里没有 alpha。

### 5. H3 的反转：H1 vs H1b 下 turn 分位结论相反

| 进场点 | Q1 (低换手锁仓板) | Q3 (高换手博弈板) |
|---|---|---|
| H1 (次日 open) | alpha -0.25%, t=-4.16 ✗ | alpha +0.22%, t=+3.42 ✓ |
| H1b (尾盘抢板) | alpha +3.08%, t=+43.73 ✓✓ | alpha +1.66%, t=+22.86 ✓ |

- H1b 下：缩量板最强（次日续涨 alpha 多）
- H1 下：缩量板最差（次日开盘缺接盘 → 低开 → 反吃 alpha）

证明 alpha 来源是**隔夜跳空高开**，缩量板的高开溢价比烂板更高。

## 散户能赚钱的可能版本（理论上）

唯一不死的路径：**T 日尾盘抢板 + 真实滑点 < 100bp**。但需要：

1. **抢板成功率折扣**：散户尾盘挂涨停价大概率挂在队尾，铁板抢成功率 < 5%，烂板 30-50%（且烂板 alpha 没那么高）
2. **次日卖出执行**：不能盯盘的散户用 T+1 14:55 提前挂收盘价单
3. **真实 cost**：粗估 100-150bp（含 100bp 抢板滑点），需要实盘验证

实际散户预期：**(抢板成功率 30%) × (1.87% alpha) - cost ≈ 0.4-0.5%/成功笔**。一年 6,697 个 Q1 候选，按 30% 成交 = 2,000 笔。理论年化 = 2,000 × 0.005 / 总仓位 ≈ 100% 的 turnover 收益（如果分散）—— 但**一切建立在精准择时 + 严格执行 + 真实滑点假设上**。

## 综合判定

**对 2 万小资金的实战指导**：

| 玩法 | 评级 | 备注 |
|---|---|---|
| 机械化 H1（次日开盘买无脑追） | ⛔ 禁 | 显著负，每笔扣 0.5-0.6% |
| 机械化 V1（次日开盘买铁板） | ⛔ 大禁 | 6.7% 胜率，几乎确定亏损 |
| V3 0-5% 追板 | ⛔ 禁 | 没 alpha，cost 让它确定亏 |
| H1b × Q1（尾盘抢缩量板）+ 实盘验证 | ⚠️ 谨慎 | 数学有 alpha，但执行摩擦未知，**先纸面跟单 1 个月** |
| 不做这个战法 | ✓ 推荐 | **诚实研究的结论：避开是最好的选择** |

## 这次研究的方法论价值

不是"试出了能赚钱的策略"，而是**严格证伪了一组散户共识**：
- ✗ "铁板续涨" — 实际 6.7% 胜率
- ✗ "0-5% 追板" — alpha 不显著
- ✗ "次日开盘买首板" — 显著负
- ✓ "涨停后隔夜跳空 +2%" — 真实但不可套利（limits to arbitrage）

**避免亏损的研究价值 = 研究出有效策略的研究价值**。这次研究让用户避免了一类高摩擦低期望的玩法。
